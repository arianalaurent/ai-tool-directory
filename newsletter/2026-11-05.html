Mistral and Moonshot open their giant models, an open coding model for one workstation, and a free AI playtester

9 verified releases this week, plus our pick for building apps and code with AI.

Hi friend,

Here's what launched in AI this week, checked against each maker's own announcement before it went on the site. New entries stay unrated until we've reviewed them, so treat these as "worth a look," not verdicts.

New this week

  • Ripple-65B Preview (Ricursive Intelligence, Nov 4). A 65B open-weight coding model under Apache 2.0, pretrained from scratch. Ricursive says it sets a new high for U.S. open-weight models on agentic coding and reports 80.5% on Terminal-Bench 2.1. You can also use it hosted on Together AI, GMI Cloud and OpenRouter. Announcement
  • TwIL-8B (webAI, Nov 4). A small reasoning model for math and code that runs on a laptop or small desktop, with GGUF builds for local apps. The license is non-commercial, so it's for personal and research use. Announcement
  • Hy4 (Tencent, Nov 4). Tencent's Hunyuan model now understands images and can use a computer, per Tencent. It's API-only for now on Tencent Cloud and OpenRouter, at $0.834 per million input tokens and $2.501 per million output tokens. Tencent says open weights are coming but hasn't released them. Announcement
  • P-H3-Image (Pruna AI, Nov 3). An open image generation and editing model that Pruna says works in 8 steps instead of 50 and runs on a much smaller GPU than the model it's built from. It's strongest at photorealism, per Pruna, and there's a free demo on Hugging Face. Check the custom license before commercial use. Announcement
  • Hydrogen-1.0 (Deep Principle, Nov 2). An open-weight model (MIT license) for scientific research: reasoning through questions, running simulations and planning experiments, per Deep Principle. Announcement
  • LongCat-2.5 (Meituan, Nov 2). Meituan's multimodal agent model for long, multi-step tasks and visual coding like design and 3D. API only at launch. Announcement
  • Aura Autopilot (Aura, Oct 30). A free, open-source agent that plays your game inside Unreal, Unity or Godot from a plain-English goal, then reports bugs with a video of the session. Announcement
  • Pika H3 Flex (Pika, Oct 29). An open-weight video model with a soundtrack, exportable audio stems and up to 4K output. Pika says its API starts at $0.01 per second. Announcement
  • Mistral Large 4 (Mistral, Oct 29). Mistral released the weights of its 1T-parameter multimodal model on Hugging Face and says it's the #1 open model on Cognition's FrontierCode. You'll need serious GPU hardware to run it yourself. Announcement

Update: Kimi K3.1 Pro, which we covered last week, now has its weights on Hugging Face (released Nov 4). Running it locally takes datacenter-class hardware. Moonshot's post

Use case of the week: build apps and write code with AI

Best pick: Cursor (our rating 9.0, #1 in Coding & Vibe Coding). A VS Code-style editor built around AI agents, with codebase-aware chat, agent mode and tab completion. It has a free tier. Skip it if you're locked into JetBrains.

  • Not a coder? Lovable (8.0) turns a prompt into a working web app, with Supabase and GitHub built in.
  • Live in the terminal? Claude Code (8.5) is Anthropic's coding agent for multi-file edits and Git work.
  • Want an open model you control? This week's Ripple-65B Preview is worth a try if you have a high-end workstation. It's still unrated while we test it.
