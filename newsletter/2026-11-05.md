# AI Tool Directory weekly: Nov 5, 2026

**Subject line:** Mistral and Moonshot open their giant models, an open coding model for one workstation, and a free AI playtester
**Preview text:** 9 verified releases this week, plus our pick for building apps and code with AI.

Hi friend,

Here's what launched in AI this week, checked against each maker's own announcement before it went on the site. New entries stay unrated until we've reviewed them, so treat these as "worth a look," not verdicts.

## New this week

- **[Ripple-65B Preview](https://aitooldirectory-beta.vercel.app/tool.html?id=ripple65b)** (Ricursive Intelligence, Nov 4). A 65B open-weight coding model under Apache 2.0, pretrained from scratch. Ricursive says it sets a new high for U.S. open-weight models on agentic coding and reports 80.5% on Terminal-Bench 2.1. You can also use it hosted on Together AI, GMI Cloud and OpenRouter. [Announcement](https://x.com/RicursiveAI/status/2118046765857546733)
- **[TwIL-8B](https://aitooldirectory-beta.vercel.app/tool.html?id=twil8b)** (webAI, Nov 4). A small reasoning model for math and code that runs on a laptop or small desktop, with GGUF builds for local apps. The license is non-commercial, so it's for personal and research use. [Announcement](https://x.com/thewebAI/status/2118054125737070659)
- **[Hy4](https://aitooldirectory-beta.vercel.app/tool.html?id=hy4)** (Tencent, Nov 4). Tencent's Hunyuan model now understands images and can use a computer, per Tencent. It's API-only for now on Tencent Cloud and OpenRouter, at $0.834 per million input tokens and $2.501 per million output tokens. Tencent says open weights are coming but hasn't released them. [Announcement](https://x.com/TencentHunyuan/status/2117870250838630539)
- **[P-H3-Image](https://aitooldirectory-beta.vercel.app/tool.html?id=ph3image)** (Pruna AI, Nov 3). An open image generation and editing model that Pruna says works in 8 steps instead of 50 and runs on a much smaller GPU than the model it's built from. It's strongest at photorealism, per Pruna, and there's a free demo on Hugging Face. Check the custom license before commercial use. [Announcement](https://x.com/PrunaAI/status/2117663564487926043)
- **[Hydrogen-1.0](https://aitooldirectory-beta.vercel.app/tool.html?id=hydrogen10)** (Deep Principle, Nov 2). An open-weight model (MIT license) for scientific research: reasoning through questions, running simulations and planning experiments, per Deep Principle. [Announcement](https://x.com/DeepPrinciple/status/2117249008972550447)
- **[LongCat-2.5](https://aitooldirectory-beta.vercel.app/tool.html?id=longcat25)** (Meituan, Nov 2). Meituan's multimodal agent model for long, multi-step tasks and visual coding like design and 3D. API only at launch. [Announcement](https://x.com/Meituan_LongCat/status/2117264311714537633)
- **[Aura Autopilot](https://aitooldirectory-beta.vercel.app/tool.html?id=auraautopilot)** (Aura, Oct 30). A free, open-source agent that plays your game inside Unreal, Unity or Godot from a plain-English goal, then reports bugs with a video of the session. [Announcement](https://x.com/Aura_Assistant/status/2116191580063404100)
- **[Pika H3 Flex](https://aitooldirectory-beta.vercel.app/tool.html?id=pikah3flex)** (Pika, Oct 29). An open-weight video model with a soundtrack, exportable audio stems and up to 4K output. Pika says its API starts at $0.01 per second. [Announcement](https://x.com/pika_labs/status/2115860471215788262)
- **[Mistral Large 4](https://aitooldirectory-beta.vercel.app/tool.html?id=mistrallarge4)** (Mistral, Oct 29). Mistral released the weights of its 1T-parameter multimodal model on Hugging Face and says it's the #1 open model on Cognition's FrontierCode. You'll need serious GPU hardware to run it yourself. [Announcement](https://x.com/MistralAI/status/2115811242556137820)

**Update:** **[Kimi K3.1 Pro](https://aitooldirectory-beta.vercel.app/tool.html?id=kimik31pro)**, which we covered last week, now has its weights on Hugging Face (released Nov 4). Running it locally takes datacenter-class hardware. [Moonshot's post](https://x.com/Kimi_Moonshot/status/2118010528123773297)

## Use case of the week: build apps and write code with AI

**Best pick: [Cursor](https://aitooldirectory-beta.vercel.app/tool.html?id=cursor)** (our rating 9.0, #1 in Coding & Vibe Coding). A VS Code-style editor built around AI agents, with codebase-aware chat, agent mode and tab completion. It has a free tier. Skip it if you're locked into JetBrains.

- Not a coder? **[Lovable](https://aitooldirectory-beta.vercel.app/tool.html?id=lovable)** (8.0) turns a prompt into a working web app, with Supabase and GitHub built in.
- Live in the terminal? **[Claude Code](https://aitooldirectory-beta.vercel.app/tool.html?id=claudecode)** (8.5) is Anthropic's coding agent for multi-file edits and Git work.
- Want an open model you control? This week's **[Ripple-65B Preview](https://aitooldirectory-beta.vercel.app/tool.html?id=ripple65b)** is worth a try if you have a high-end workstation. It's still unrated while we test it.
